## Body

On a conveyor belt, there are T-shirts lined up in a line. Each T-shirt can be represented by a word
indicating its SIZE (small, medium, large) and the NUMBER drawn on it.

For example, a small t-shirt with the number 7 will be represented as 7 small.

The robot repeatedly executes the following instructions as long as there are any T-shirts on the
conveyor belt:
1. Take the first T-shirt in the line.
2. If it is small, move it to container X.
3. If it is large, move it to container Y.
4. If it is medium, check the number on the T-shirt:
- if it is even, move the T-shirt to container X.
- if it is odd, move the T-shirt to container Y.

Initially, container Y already contains one T-shirt and there are following T-shirts on the
conveyor belt:

6 small, 2 medium, 7 small, 8 large, 4 medium, 4 small, 7 small, 3 large, 1 medium

## Question/Challenge - for the brochures

What is the final number of T-shirts in containers X and Y?
